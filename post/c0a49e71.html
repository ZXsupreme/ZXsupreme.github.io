Jenkins 部署指南

发表于2026-05-12|更新于2026-05-12|技术运维Jenkins

通过本指南可快速部署 Jenkins

背景

手动打包部署的步骤非常繁琐，又费时，为此寻找一份解决该问题的解决方案。

操作步骤

安装工具

在 macOS 上部署 Jenkins，最推荐使用 Homebrew 进行安装，过程非常简便。

  1. 安装 Homebrew

    如果 Mac 尚未安装 Homebrew 包管理器，请先在终端（Terminal）中执行以下命令进行安装

  1. 安装 Jenkins

Jenkins 分为最新版和长期支持版（LTS）。这里使用的是更稳定的 LTS 版本。

  1. 启动 Jenkins 服务

安装完成后，使用 brew services 命令将 Jenkins 作为后台服务启动。这样即使重启电脑，Jenkins 也会自动运行。

如果不希望重启电脑 Jenkins 自动运行，也可运行

其他常用服务管理命令：

  • 停止服务: brew services stop jenkins-lts
  • 重启服务: brew services restart jenkins-lts
  • 查看服务状态: brew services list

初始配置

  1. 访问 Jenkins
    服务启动成功后，打开浏览器访问 http://localhost:8080。你将看到解锁 Jenkins 的页面。

  2. 获取初始管理员密码
    首次访问需要输入初始管理员密码。在终端中执行以下命令即可查看：

    复制终端输出的密码，粘贴到网页的输入框中。

  3. 完成向导设置

    • 安装插件: 点击「安装推荐的插件」，Jenkins 会自动安装 Git、SSH、Pipeline 等常用插件。

  • 创建管理员账户: 插件安装完成后，根据提示设置你的管理员用户名、密码和邮箱地址。

  • 配置实例 URL: 保持默认的 http://localhost:8080 即可，然后点击“保存并完成”。

Jenkins 配置

  1. 进入 Jenkins 首页，【新建任务】选择【创建文件夹】

  2. 在刚刚创建的文件夹中【新建任务】，选择【流水线】，配置流水线的【Pipeline script】

    这里可以让AI生成

  3. 在刚刚创建的文件夹中【新建视图】，选择【列表视图】（之所以选择这个视图为了后面分权限做准备）

  4. 在【列表视图】设置权限

    • 一个一个任务勾选【太麻烦了】

    • 使用正则表达式匹配

    在【编辑视图】中【任务列表】下勾选“使用正则表达式在视图中显示任务”，输入相应的正则表达式即可

  5. 在【系统管理】->【全局工具配置】中配置 git、maven、node

  6. 在【系统管理】->【系统配置】中配置主机信息（需要插件 Publish Over SSH 支持）

重要插件

  • Publish Over SSH：用于连接远程服务器
  • Role-based Authorization Strategy：用于设置访问权限
  • Stage View：以一目了然的表格形式展示流水线各阶段的执行历史
  • Blue Ocean：提供一套 全新的、现代化风格的 UI

权限配置（可选）

如果需要不同用户访问不同的任务可使用，需要插件 Role-based Authorization Strategy 支持

  1. 进入【系统管理】->【管理用户】中创建一个新用户
  2. 进入【系统管理】->【Manage and Assign Roles】->【Manage Roles】中配置【Global roles】和【item roles】
  3. 进入【系统管理】->【Manage and Assign Roles】->【Assign Roles】中为角色配置不同权限

注意：这里设置完【Manage Roles】后需要进入【Assign Roles】为管理员配置权限，否则可能导致退出后登录不了

踩过的坑与解决方案

文件路径问题

报错现象 根本原因 解决方案
./utils/start-app.sh: No such file or directory 启动脚本内部使用相对路径，但执行时工作目录不正确 在脚本开头添加 cd $(dirname $0) 切换到脚本所在目录
No such file or directory (启动脚本) Jenkins执行命令时的当前目录不是用户家目录 显式添加 cd ~ 切换到用户家目录

文件上传问题

报错现象 根本原因 解决方案
文件上传到 /dict/dict/apps/... 目录 SSH插件将绝对路径误判为相对路径 使用 removePrefix: "target" 去除本地路径前缀
文件上传后找不到 路径拼接错误导致目录嵌套 使用相对路径 ./apps/... 代替绝对路径 /dict/apps/...

用户权限问题

报错现象 根本原因 解决方案
无法登录账号 设置角色时未给当前使用用户指定角色，导致登录后无法使用 1.编辑配置文件 vi ~/.jenkins/config.xml
2.在文件中搜索 <authorizationStrategy> 这一行
3.将其改为原来的即可

将<authorizationStrategy class="com.michelin.cio.hudson.plugins.rolestrategy.RoleBasedAuthorizationStrategy"/>替换为<authorizationStrategy class="hudson.security.AuthorizationStrategy$Unsecured"/>

避坑指南

SSH插件使用注意事项

  • 避免在 remoteDirectory 中使用可能引起歧义的路径名
  • 充分利用 removePrefix 参数控制上传路径结构
  • 使用 execCommand 进行上传后验证

Jenkins Pipeline编写建议

  • 添加详细的日志输出，便于问题排查
  • 使用变量管理路径，提高脚本可维护性
  • 添加错误处理和退出码检查
